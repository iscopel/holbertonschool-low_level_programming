# C - More malloc, free

This directory covers more dynamic memory allocation in C using `malloc`, `free` and `exit`.

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file with all function prototypes |
| `0-malloc_checked.c` | Allocates memory with `malloc`, exits with status 98 on failure |
| `1-string_nconcat.c` | Concatenates `s1` with the first `n` bytes of `s2` |
| `2-calloc.c` | Allocates zeroed memory for an array, like `calloc` |
| `3-array_range.c` | Creates an array of integers from `min` to `max` |
