# C - malloc, free

This directory covers dynamic memory allocation in C using `malloc` and `free`.

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file with all function prototypes |
| `0-create_array.c` | Creates an array of chars initialized with a specific char |
| `1-strdup.c` | Returns a pointer to a newly allocated copy of a string |
| `2-str_concat.c` | Concatenates two strings into newly allocated memory |
| `3-alloc_grid.c` | Returns a pointer to a 2D array of integers initialized to 0 |
| `4-free_grid.c` | Frees a 2D grid created by `alloc_grid` |
