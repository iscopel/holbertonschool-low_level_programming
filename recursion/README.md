# C - Recursion

This directory covers recursion in C. No loops, no static variables, and no standard library functions are used; output is done with `_putchar`.

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file with all function prototypes, including `_putchar` |
| `0-puts_recursion.c` | Prints a string, followed by a new line |
| `1-print_rev_recursion.c` | Prints a string in reverse |
| `2-strlen_recursion.c` | Returns the length of a string |
| `3-factorial.c` | Returns the factorial of a number, or -1 if it is negative |
| `4-pow_recursion.c` | Returns `x` raised to the power of `y`, or -1 if `y` is negative |
| `5-sqrt_recursion.c` | Returns the natural square root of a number, or -1 if there is none |
| `6-is_prime_number.c` | Returns 1 if a number is prime, otherwise 0 |
